# Job Queue Dashboard

Project structure for a React + NestJS Mini Job Queue Dashboard.

## Backend

Located in `backend/`.

SQLite database file/path:
`backend/jobs.sqlite`

Environment:
`DATABASE_URL="file:./jobs.sqlite"`

## Frontend

Located in `frontend/`.

API environment:
`VITE_API_URL=http://localhost:3000`

## Note

This package contains the requested file/folder structure and starter files.
The actual assignment logic, validation, concurrency handling, persistence implementation, and UI behavior can be added to these files.
